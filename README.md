# SExtract

SExtract вирізає аудіофрагменти з аудіо- та відеофайлів і зберігає їх у WAV.
Файли обробляються локально; завантаження на сервер немає.
Час початку й кінця фрагмента можна задавати повзунками або вручну у форматі
`HH:MM:SS`.
Аудіо записується під час відтворення фрагмента, а семпли одразу зберігаються у
форматі WAV, щоб не тримати в пам’яті повну декодовану копію вихідного файлу.

## Запуск у браузері

Відкрийте `index.html` у сучасному браузері.

## Portable-версія для Windows

У папці `windows` є застосунок WebView2 та сценарій локальної збірки `build.bat`.
Для автоматичної збірки на GitHub достатньо запушити зміни в репозиторій.
Після завершення відкрийте **Actions**, виберіть останній запуск
**Build SExtract Windows portable** і завантажте артефакт
`SExtract-Portable-Windows-x64`.

GitHub компілює один self-contained `SExtract.exe`, у який входять .NET runtime
і файли вебзастосунку. Для запуску все одно потрібен Microsoft Edge WebView2
Runtime (зазвичай уже є у Windows 11). Це portable-файл без інсталятора, а не
повністю автономна програма без системних компонентів.

Деталі наведено у [windows/README.md](./windows/README.md).
